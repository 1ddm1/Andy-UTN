Posicionamiento static

El posicionamiento static es el valor por defecto de todos los elementos HTML. Los elementos con posicionamiento static se colocan en el flujo normal del documento, uno después del otro, sin superponerse.

Posicionamiento relative

El posicionamiento relative permite mover un elemento desde su posición original en el flujo del documento. Se puede usar para ajustar la posición de un elemento sin afectar a los demás elementos.

Absolute

El posicionamiento absolute permite colocar un elemento en una posición específica dentro de su contenedor más cercano que tenga un posicionamiento relativo, absoluto o fijo. El elemento se elimina del flujo normal del documento y puede superponerse a otros elementos.

Nuevo

Fixed

El posicionamiento fixed permite fijar un elemento en una posición específica dentro de la ventana del navegador, independientemente del desplazamiento de la página. El elemento se mantiene visible mientras se desplaza el contenido.

Caja Fija

Sticky

El posicionamiento sticky combina características de los posicionamientos relative y fixed. Un elemento con posicionamiento sticky se comporta como relative hasta que alcanza un umbral definido, momento en el cual se "pega" a la posición especificada y se mantiene visible mientras se desplaza el contenido.
